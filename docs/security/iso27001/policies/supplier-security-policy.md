# Supplier security policy

Before use, classify the supplier, data, processing purpose, locations/subprocessors, availability dependency and exit path. Review security/privacy terms, breach notification, access controls, encryption, retention/deletion, continuity, assurance reports and regulatory obligations.

Technical onboarding uses separate environment credentials, least privilege, allowlisted endpoints/assets, signature validation where available, monitored errors, fail-closed safety and documented rotation. No supplier ID becomes SayaraForce tenant/plan identity.

Critical suppliers are reviewed annually and after material incident/term/subprocessor/architecture change. Offboarding revokes credentials/webhooks/access, exports required records, confirms deletion and updates data flows/risk. Exceptions need owner/security/legal approval and expiry.
