# Information security policy

SayaraForce protects confidentiality, integrity, availability, privacy and tenant isolation proportionate to risk. Security applies to every plan and is not a commercial entitlement.

- Access is least privilege, named where possible, protected by MFA for privileged/human administration, reviewed quarterly and revoked promptly.
- Restricted material is held only in approved secret/encryption systems and never in Git, chat, screenshots, tickets or routine logs.
- Production and staging remain isolated. Production change requires explicit approval, tested commit provenance, backup/rollback and monitored verification.
- Customer data is processed only for documented purposes and retained/deleted under approved legal policy.
- High/critical findings block release unless the accountable authority records a time-bound exception and compensating controls.
- Security events are reported immediately through the incident process; good-faith reporting is protected.
- Suppliers, code, configuration and cloud resources are assessed throughout their lifecycle.

The accountable executive approves this policy annually. The security owner maintains the ISMS-aligned controls and evidence; all personnel and contractors must comply.
