# Acceptable use policy

Authorised users must use approved accounts/devices/channels, protect credentials and recovery material, enable required MFA, report suspicious events, and access only information needed for their role/tenant.

Prohibited: credential sharing, bypassing security/entitlements/tenant boundaries, production testing, copying real data to staging, unapproved exports/suppliers/AI tools, pasting secrets/customer data into chat or tickets, disabling TLS/CSRF/signatures/logging, sending staging communications to real customers, or attempting provider/cloud changes outside authority.

Company devices should be encrypted, patched, locked and protected by approved endpoint controls; evidence and detailed workforce sanctions remain an organisational HR responsibility. Monitoring is limited to legitimate security/operational purposes and applicable law/policy.
